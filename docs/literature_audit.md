# Literature And Novelty Audit Notes

The novelty claim is probabilistic. The reviewed work includes robot self-modeling, damage recovery, active learning, active system identification, causal failure diagnosis, robot-learning failure benchmarks, affordance learning, sim-to-real transfer, embodied foundation models, multi-robot systems, soft-robot co-design, and tactile learning.

Near precedents include active exploration for system identification, reset-free/intelligent trial-and-error damage recovery, causal failure prediction, failure-aware robot learning, and recent work explicitly treating probing as intervention. The proposed project should therefore avoid claiming novelty for probing, failure data, or system identification in general.

Narrow claim to audit further: no direct precedent was located for a robot evaluation protocol in which paired, nominally task-neutral physical actions are treated as negative-control interventions for diagnosing hidden embodiment changes while measuring both information gain and task-state disturbance.
